# Electric scooter landing page

One of my first HTML and CSS exercises from my software development training: a multi-page landing page for a fictional electric scooter brand, with a home page, about and contact pages, and CSS-only feature bars.

Open `Landing-Page-Scooter/index.html` in a browser to view it. No build step or dependencies.

The text is placeholder copy and the product photo is loaded from an external site, so this is a layout exercise rather than a finished site.
